# 🎙️ دليل تسجيل صوت العميل (لـ fine-tune عالي الجودة)

> الهدف: تسجيل **نضيف ومتنوّع** يمثّل صوت العميل في **أسلوب الإعلان**،
> عشان الموديل يتعلّم الجرس + الأداء.

---

## 1) المعدات
| البند | مقبول | ممتاز |
| --- | --- | --- |
| الميكروفون | مايك موبايل قريب | مايك USB/كارت صوتي (SAMSON, Blue, Rode) |
| التردد | 16kHz | **24kHz+** |
| القنوات | أحادي | أحادي |
| التنسيق | mp3 | **wav** |

## 2) المكان
- ✅ أوضة فيها سجاد/ستاير/كنب (تقلل الصدى).
- ✅ اقفل الشبابيك والمراوح والتكييف.
- ❌ بلاش أوضة فاضية (صدى)، ولا جنب شارع.

## 3) الأداء والنبرة
- اتكلم **بنفس الإحساس** اللي عايزه في الإعلانات (حماس/هدوء/دفء).
- **نوّع**: جمل قصيرة وطويلة، أسئلة، تعجب، أرقام.
- طبيعي ومريح — مش قراءة روبوتية.
- سيب **وقفة صغيرة** بين الجمل (يسهّل التقطيع).

## 4) الكم المطلوب
| المدة | النتيجة |
| --- | --- |
| 5–10 دقايق | تشابه مقبول |
| **15–30 دقيقة** | ⭐ الحلو |
| أكتر من ساعة | مكسب أقل + تدريب أطول |

## 5) الجُمل — إزاي تجهّز النص
- جملة/جملتين لكل مقطع (2–15 ثانية).
- اكتب النص **بالظبط** اللي بيتقال (حتى كلمة «يعني»).
- اقسم الملفات: `clip01.wav` / `clip02.wav` …
- اكتب النصوص في `transcripts.txt`:
  ```
  clip01.wav|جرب قهوة بون النهاردة طعم أصلي
  clip02.wav|خصم خمسين في المية لغاية آخر اليوم
  ```

## 6) أخطاء شائعة
| الغلط | الأثر |
| --- | --- |
| موسيقى/صدى في الخلفية | بيتنسخوا مع الصوت ❌ |
| نص مش مطابق للكلام | يتعلّم نطق غلط ❌ |
| كل المقاطع بنفس النبرة المسطّحة | أداء ممل ❌ |
| مقاطع أطول من 20 ثانية | بتتقطّع/تترفض |
| صوت واطي جداً أو مشبّع | جودة سيئة |

## 7) تشيك ليست قبل التسليم
- [ ] الأوضة هادية (مفيش ضجة خلفية).
- [ ] المدة الكلية ≥ 15 دقيقة.
- [ ] كل مقطع له نص مطابق بالظبط.
- [ ] مفيش موسيقى أو صدى.
- [ ] موافقة العميل **مكتوبة** ✅.
- [ ] شغّلت التجهيز والفحص:
  ```powershell
  .\.venv\Scripts\python.exe finetune\prepare_dataset.py --in data/voice_client --transcripts data/voice_client/transcripts.txt --out finetune/dataset
  .\.venv\Scripts\python.exe finetune\train_lora.py --check
  ```
