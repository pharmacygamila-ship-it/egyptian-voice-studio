# 🧬 مسار الاستنساخ «بنفس الأداء الصوتي»

> الهدف: نطلّع صوت العميل **بنفس الإحساس والأداء** (نفس نبرة الحماس/الهدوء،
> نفس الإيقاع، نفس طريقة النطق) — مش بس تشابه في الجرس.

فيه مسارين. **ابدأ بالأول (أسرع ورخيص)، والتنين مكمّلين لبعض.**

---

## المسار (أ): Zero-shot بتسجيل مرجعي مُختار بعناية ⭐ (ابدأ هنا)

الموديل بيستنسخ **الأداء** من المقطع المرجعي. يعني لو المرجع حماسي، الناتج حماسي.

**قواعد اختيار المرجع:**
| القاعدة | ليه |
| --- | --- |
| 10–30 ثانية | الطول الأمثل للاستنساخ |
| **بنفس الإحساس** اللي عايزه في الإعلان | الأداء بيتنقل من المرجع |
| صوت نضيف (من غير موسيقى/صدى/ضجة) | الضجة بتتنسخ كمان |
| جملة كاملة، مش كلمات مقطّعة | يحافظ على الإيقاع |
| بصيغة wav أحادي 16kHz+ | جودة أعلى |

**الاستخدام:**
```powershell
# من الواجهة (تاب «استنساخ صوت») أو:
.\.venv\Scripts\python.exe poc_generate.py --ref-audio client_ref.wav --ref-text "نص المقطع" `
    --text "الإعلان الجديد" --out data/outputs/ad_client.wav
```
💡 **حيلة الأداء:** لو عايز إعلان حماسي، ارفع مقطع حماسي. لو عايز هادي، ارفع مقطع هادي.
ممكن كمان تزوّد `--guidance` (2.0–3.0) لتمسّك أقوى بالمرجع.

## المسار (ب): Fine-tune (LoRA) — أقصى تشابه

بيخلّي الموديل **يتعلّم صوت العميل**، فالشبه يطلع أعلى حتى من غير مرجع.

### 1) التسجيل
| البند | التوصية |
| --- | --- |
| المدة | **10–30 دقيقة** كلام نضيف (أكتر = أحسن، بحدود) |
| الميكروفون | أي مايك نضيف + **أوضة هادية** (من غير صدى) |
| الأسلوب | نفس أسلوب الإعلان (إيقاع/إحساس) |
| التنويع | جمل مختلفة، مش نفس الجملة |
| التنسيق | wav أو mp3، 16kHz+ |
| التنظيم | ملف لكل جملة/مقطع + نصه |

**دليل التسجيل الكامل في [`RECORDING.md`](RECORDING.md).**

### 2) تجهيز الداتاسِت (شغّال محلياً)
بيحوّل التسجيلات لمقاطع منظّفة 24kHz أحادية + يقسّمها تدريب/تحقق:
```powershell
.\.venv\Scripts\python.exe finetune\prepare_dataset.py `
    --in data/voice_client `
    --transcripts data/voice_client/transcripts.txt `
    --out finetune/dataset
```
تنسيق `transcripts.txt` (سطر لكل مقطع): `clip01.wav|النص اللي بيتقال`
(أو `.txt` جنب كل تسجيل بنفس الاسم).

الناتج:
```
finetune/dataset/
  clips/        مقاطع منظّفة
  train.jsonl   بيانات التدريب
  val.jsonl     بيانات التحقق
  report.json   تقرير الجودة
```

### 3) فحص الداتاسِت وخطط التدريب
```powershell
.\.venv\Scripts\python.exe finetune\train_lora.py --check
```

### 4) التدريب (محتاج GPU)
```bash
python finetune/train_lora.py --dataset finetune/dataset --epochs 20 --lora-rank 16
```
- مكان التشغيل: **Colab / RunPod / Modal** (نفس اللي في `deploy/`).
- المخرج: adapter (LoRA) ينحمّل فوق الموديل الأساسي.

> 🔌 **نقطة تركيب:** الـ API الرسمي **للتدريب** في OmniVoice بيتغيّر بين الإصدارات،
> فدالة `build_trainer()` في `finetune/train_lora.py` فيها مكان واضح توصّل فيه
> الـ trainer الرسمي حسب نسختك (rank/alpha/LR كلها جاهزة في `TrainConfig`).

### 5) التقييم (اختياري بس مفيد)
- **WER**: أعِد تفريغ الناتج بـ ASR مصري → يكشف النطق الغلط.
- **تشابه الصوت**: cosine بين embedding الناتج والصوت الأصلي.
- **MOS يدوي**: الأذن البشرية هي الحكم النهائي.

---

## مسار موصى به عملياً

```
تسجيل 15 دقيقة من العميل
      │
      ├─(فوراً) مقطع 15–20 ثانية بنفس إحساس الإعلان → Zero-shot → تسليم سريع
      │
      └─(لو محتاج شبه أعلى) fine-tune LoRA → نموذج مخصص للعميل
```
